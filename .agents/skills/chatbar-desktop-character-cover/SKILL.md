# Desktop original character covers

- Shared `CharacterCard.coverImage` and `PackagedCharacterCard.coverImageResourceId` are optional originals, separate from avatar/background. `CharacterCardTransferCore` defaults to official-compatible9, excluding the independent-cover reference/resource without reading or changing its stored original. Explicit `DESKTOP_COVER_V10` retains it; internal duplication keeps the full original. `forExportCompatibility` preserves cover aliases still referenced by avatar/background/person images. The current reader accepts3–10; official1.4.11 accepts3–9, so full10 is not Android parity.
- `OriginalCharacterCover` validates PNG framing/CRC and strips case-insensitive ChatBarCharacter/chara/ccv3 text chunks (tEXt/zTXt/iTXt), preserving every other encoded block. `CharacterCardPngPackageCodec` uses it before attaching current data. Classifier and typed native/ST ingress prefer embedded originals. PNG resources exclude nested old card data; nonPNG sources stay byte exact.
- `DesktopCharacterResourceStore` owns CREATE_NEW `images/character-covers` and only that additional nested directory. `DesktopCharacterDraftResources` stages/copies/materializes covers and admits restored absolute draft paths only within its strictly validated root. Editor draft/save fields and `desktopCharacterResourceReferences` retain covers.
- The editor provides replacement/clear/copy-avatar without original crop. JSON and PNG export dialogs default to official-compatible9 and explicitly offer full10 with an unsupported-official warning. PNG rendering keeps original appearance/dimensions independently of payload compatibility; `renderExportImage` skips logo/resampling for original PNG. AppContainer wires production JSON/PNG/edited-export same-file guards. Draft identity rejects canceled/reentered exports; choosing full JSON rechecks captured card/resources. Temporary replacements and undo affect only export copies.
- Explicit generated-cover application stages a separate full-image cover in addition to its existing avatar crop/background; candidate-only application retains the candidate boundary. `DesktopCharacterImageTest` covers retained original assignments and cover save alongside its existing retry/rollback checks.
- Backup resource registry, `desktopName` and merge `addMedia` retain dedicated cover storage. Existing reference cleanup remains authoritative. Checks: shared `OriginalCharacterCoverTest`/`CharacterCardExportCompatibilityTest`; Desktop original-cover/backup and `DesktopCharacterExportCompatibilityTest`/`UiTest`, plus transfer/classifier/editor neighbors. The frozen `interop/official1411` reader is copied with namespace-only transforms and per-file origins; it validates compatible outputs and refuses10. Actual default controller JSON/PNG and explicit full routes retain independent source bytes. Android prepared source is not execution evidence.
