# Android · NovelAI 批量生图测试 n1

这是 MisakaPiano 下游 Fork 的独立安卓测试版，基于官方 CCB 1.4.12，尚未合并至官方版本。桌面端对应功能仍在独立验证，本页面不提供桌面安装包。

## 下载与安装

下载下面 Assets 中的 **CCB-NovelAI-Android-test-n1.zip**，解压后安装 APK。Android 8.0 及以上可安装；应用名为 **CCB 批量生图测试 n1**，独立包名，可与正式版共存。ZIP 内含详细测试清单、构建信息、合成界面截图和文件校验表。

这是 debug 签名测试包，不是正式升级通道。尚未经过测试用户的实机验收，不包含此前单独的封面／玩家身份 c1 分支。

## 本轮测试内容

- 工作室及会话手动生图：一次请求 1–4 张，连续生成至指定目标（最多 100 张），例如 4＋4＋2。
- 批次间固定等待或范围随机等待、倒计时、暂停／继续／停止；首批直接开始，末批后不多等。
- 本次任务费用估算预算默认 0；逐批重新检查，计费未知、余额不足或超出估算预算时停止。
- 429 暂停并遵守服务端冷却，需手动继续；不确定断线不自动补发。停止后保留已成功保存的图片。
- 复用原有 Prompt、HTTP 参数、费用估算及持久化路径；会话自动生图保持原有单图行为。

## 先做无账号验收

1. 安装后打开第二个图标 **CCB 离线批量验收**。
2. 保持默认每批 4 张、目标 10 张、固定 1 秒、“成功”及“会话保存”，勾选确认并开始。
3. 应显示请求 **[4, 4, 2]**、已保存 **10/10**；重新读取磁盘、关闭再打开后，结果仍在且任务不自动重启。
4. 按 ZIP 内的 `验收步骤.txt` 继续测试随机等待、暂停／停止、合成费用及 429。

这个入口使用合成 2×1 PNG 和模拟传输，不需要账号，不向 NovelAI 发请求，不产生真实生图费用。它验证共享策略、真实请求参数／流解析器和隔离仓储；不能替代正常主界面、真实提供商或 Android 后台行为验收。

## 消费与限流说明

正常主界面连接真实账号后可能消耗 Anlas／V5 使用额度。本轮开发没有执行真实账号或付费测试；仅需离线验收时不要填写真实 Token。一次多图、连续单图均不能保证免费；预算只是本地估算门槛，不是服务器保证的扣费上限。停止或断线后，已发送请求仍可能被处理和计费。

固定／随机等待仅用于请求节奏控制，不保证免限流、账号安全或符合服务端规则。请参阅 [NovelAI 图片文档](https://docs.novelai.net/en/image/)、[额度说明](https://docs.novelai.net/en/faq/)及[服务条款](https://novelai.net/terms)。
