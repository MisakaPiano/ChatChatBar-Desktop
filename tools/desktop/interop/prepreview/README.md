# Explicit private export audit tools

These opt-in test-classpath tools are not application components. They do not import, prepare a restore, access SecretStore, create a journal or authorize business. No real password/key belongs in source, command arguments, environment, transcripts, screenshots or public evidence.

`archive_census.py <explicit-directory>` enumerates only the caller-authorized directory, skips reparse/special entries and refuses unsafe ancestors. Windows file handles deny write/delete sharing. It hashes source bytes before/after privately in memory and outputs fixed categories/counts only. It recognizes untrusted backup header claims; encrypted payloads are not decrypted. ZIP census streams CRC with a bounded central-directory/expansion budget; it does not validate SaveSlot schema/reference graphs. It never extracts files. Directory-race resistance against a malicious same-user writer is not proved. No arbitrary directory should be supplied without explicit user authorization.

`Run-Jvm.ps1 -Round <new-evidence-label> -Prepare` uses the existing external R0 Gradle init helper to compile only opt-in tooling and write the ignored runtime classpath. It does not change committed Gradle configuration. Testing uses `-Suites` and stores independent logs/exit/JUnit; an existing recorded round is never overwritten.

`SingleSlotReadOnlyTool` delegates one explicit file to the existing SaveSlot inspector under a read guard. Its current 64MiB expanded budget remains intact; an oversized archive can have valid ZIP CRC while being semantically UNSUPPORTED.

`StreamingEnvelopeProbe` is a supplementary **authentication-only** reader with a distinct 4GiB source/plain-stream safety budget. It reuses AppBackupCodec, streams to EOF, writes no plaintext and requires Java Console masked input. It is not an S0 limit increase. Optional `--container` additionally checks streaming local ZIP entry CRC, strict bounded transport manifest/inventory, hashes/lengths and counts using existing pinned DTOs/JSON lexer. It does **not** verify the central-directory/local consistency, Entity schemas, scope semantics, resource graphs, credentials, nested SaveSlots or restore. Output labels disclose those omissions. Full authenticated stream EOF is consumed before returning a result, including ZIP trailing bytes.

Local invocation after a successful Prepare and specific file authorization uses JDK17, `-XX:+DisableAttachMechanism -XX:-HeapDumpOnOutOfMemoryError -Xmx256m`, the generated classpath, and main class `com.example.chatbar.desktop.backup.StreamingEnvelopeProbe`, followed by the one file and optional `--container`. Refuse inherited `JAVA_TOOL_OPTIONS`, `JDK_JAVA_OPTIONS`, `_JAVA_OPTIONS`. Password is entered only at `Archive password (hidden):`; no Console means refusal. Source filenames may be visible in local OS process arguments. Do not turn on transcript/recording. No OS-wide secrecy, memory erasure, official-publisher authenticity or real Android runtime claim follows.

Public evidence contains synthetic test sources/raw test logs plus reviewed category-only real-run receipts. Real archive bytes, names, plaintext and private digests never belong in the evidence collector or Git. User-provided source files remain user-owned and unmodified.
