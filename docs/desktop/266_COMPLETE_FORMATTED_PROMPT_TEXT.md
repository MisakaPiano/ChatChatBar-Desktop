Studio新增“完整 Prompt…”：复制完整文本、读取剪贴板并预览、明确确认替换、取消及原撤销。文本覆盖画风/基础/补充/全局负词、按序角色正负词/位置/启用、实际模型和自然语言模式；不受原“复制正向时忽略画风”影响，不继承目标旧角色负词/开关。所选模型的 `useCharacterPositions` 是位置实际生效的Prompt控制位，也随源同步，仅修改目标对应模型这一位，其他模型设置不动。复制先解析实际默认模型；应用清除本机卡片绑定，其余生成参数、连续生成、参考资源、AI设计输入和账户保留目标值。完整资源及参数交换使用 `.ccbpreset`，不把文本功能称为完整资源预设。

`NovelAiStudioFullPromptClipboard`使用独立 `CCB-FULL-PROMPT/1` 前缀、配置和人类可读分段。配置为复制器生成的规范JSON，拒绝重复/非规范字段；正文保留空负词/关闭角色/尾随空行，对完整括号标题或反斜杠开头行转义，CRLF统一为LF。未知版本/分段、重复、残缺、乱序、无效角色位置/模型数量拒绝，16Mi字符为文本解析预算。不把格式标题或配置直接作为正/负词。

刻意不以旧【画风/基础】开头：原正向reader只认识正向标题，否则可能把新负向标题吞进正向正文；独立前缀使其明确拒绝。旧正向协议及其保留目标负词/位置等原语义未改。其他应用可按分段查看/取用，但直接导入需实现此格式；不声称Android、Studio Suite或NovelAI网页已有新parser，也不宣称这段结构化文本可整体贴进任意正向输入框。

Controller沿原mutex/正常数据准入保存预览基线。仅明确确认进入不可取消的原撤销/草稿提交，二次核对基线；预览、取消、错误和草稿已变化均不覆盖当前正文。窗口关闭先取消并等待原操作，再丢弃预览；正常退出清除未确认预览，不自动应用。不新增AI请求、Prompt模板或请求顺序规则。
