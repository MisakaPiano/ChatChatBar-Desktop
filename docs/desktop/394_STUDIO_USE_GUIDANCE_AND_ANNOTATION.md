2026-11-08，后继批次源码在准备，尚未交付。原15项真人功能范围通过保留，新缺陷单列。

- 用作选择目标后会把同一个auxiliary Window切换为图像引导；此前只有内容状态变化，没有独立的原地恢复/前台请求。现为明确打开意图递增activation revision，复用原Window和原图像选择；不通过重建工作区或切页面恢复。历史/当前图片的用作导入仅在成功后进入引导，错误在辅助窗口也可见。
- 工作区与引导页按真实asset/id显示基图、精确参考和每个氛围参考，包含缩略图、当前/保留状态、模式与数量、尺寸、查看/更换/移除。同图多用途独立，不去重；只有编码的参考明确无原图。更换保留当前模式与该槽参数；Vibe保留id但清除失效编码，拒绝陈旧源。移除基图连带其蒙版/聚焦框，其他参考保持，沿用原草稿、撤销及资源保留机制。此类本地准备不发请求，不改正在生成的快照。
- 导入、完整Prompt、AI应用、反推等已有共享提交会推进`promptContentRevision`；Desktop原注释任务只按可见文本/开关重算，没有消费此导入修订。现由原草稿修订和本地replay修订显式失效派生注释，翻译服务更换也重查；不关开开关、不改原文/光标/输入法/撤销。回归将用保留字段和同文导入检验，真实用户具体导入路径不冒称已独立复现。

必要检查使用合成图像/字典和原Controller：分槽移除、更换参数和撤销、陈旧来源、320/680布局，以及同文导入后实际注释像素和选择保持。用作重入另用图形环境下的原生辅助窗口，验证同Window改用途后再次打开及最小化恢复；图形条件不满足时明确跳过，不冒称真实桌面验收。
