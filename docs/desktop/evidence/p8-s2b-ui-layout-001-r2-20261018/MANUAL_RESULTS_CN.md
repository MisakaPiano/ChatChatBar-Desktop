## 用户新增停止控件反馈

原文：“那个预览的停止键还是在预览的时候出现一下吧，不然一直听完可能比较折磨，加上停止的小图标”。后续确认：“完全没看到停止按钮”。

源码 `DesktopFishPickerPresentation.kt:170` 已有仅 busy／playing 时显示的 `StudioAction("停止预览", icon = DesktopAppIcons.Stop)`，位于底部预览状态栏。存在代码和离屏语义不能证明用户在真实窗口能发现或操作它。没有本轮截图／实时 viewport／焦点证据，尚不能区分裁剪、状态时机、位置、信息层级或其他原因。保留为用户观察到的可见性缺口，根因 UNKNOWN。

明确需求：预览过程中有醒目、可达、含文字与停止图标的停止操作；下载／生成／播放、停止和关闭的原有排水语义必须保留。当前没有实施新修复，也未修改 runtime/player/store。用户反馈不能被描述成该按钮已通过人工验收。

## 测试指令本身的限制

M03 指令使用“约半屏宽”。在1920像素、scale1的诊断显示器上，半屏可能仍超过代码800dp断点。用户无法回忆面板形态，因此不能证明当时已进入紧凑 Popup。后续须明确观察“搜索在列表上方、筛选覆盖列表的浮层”，并记录真实窗口尺寸和焦点；本轮不重开、不无限重复。
