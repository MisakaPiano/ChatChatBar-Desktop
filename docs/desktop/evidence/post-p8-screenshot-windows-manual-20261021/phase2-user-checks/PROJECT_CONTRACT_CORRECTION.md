# 用户明确规则补充：截图排除所有录音

> 不存在只有录音的截图，如果有只有录音的回复就是bug。只有有文字没有录音的情况，不可以存在没有文字只有录音的情况

> 任何录音都不应该进入截图

回复必须有文字，录音可有可无且附属于文字。截图不得包含任何录音条、录音元信息或播放/操作控件，即使录音附属于正常文字回复。此要求不表示删除真实录音。

当前纯录音回复是本轮合成环境人为创建的无效领域场景，不证明生产流程产生过纯录音回复。原先把它作为支持场景的 R2-R1 工程要求及 Gate 用例与用户规则冲突，应由 Project 更正后续合同；保留历史测试、代码及证据，不抹去 RED/GREEN。

用户提供的当前预览明确显示录音条，按本次规则记 USER FAIL。B8 纯录音用例标 BLOCKED / INVALID SYNTHETIC SCENARIO，不签 USER PASS，不继续导出。

本轮未修改生产源码、发行包、合成 fixture 或音频文件。需单独授权的最小修复应审查选择列表/批量操作/整条和片段选择/预览与 PNG 导出各入口排除录音，保持文字、图片、版本及资源安全规则。还应定向核实生产创建/更新回复是否满足文字必需的领域约束，不能用合成无效 fixture 推断生产缺陷已复现。
