## 功能入口与预期

- 聊天页提供会话存档：保存新存档时选择原图/压缩图片/不含图片，另选是否包含录音；导入只加入列表，恢复必须另外确认。恢复前自动保存原会话，失败不会伪装成功。
- 会话存档同时提供复制会话与更换会话资源。重新绑定保留历史消息、版本、原格式卡及录音，附加世界书可单独选择；卡片继承的世界书仍随卡片。确认文字明确说明计时重置与历史名称/头像呈现变化。
- Data 页的整应用备份提供导出、选择文件并离线检查、两步确认恢复。普通导出不含真实凭据；含非空凭据的输入明确拒绝，原文件保留。可选密码用于官方加密容器，不会开启凭据迁移。
- 整应用恢复准备成功后显示需要正常退出，并停止接收新的写入。用户正常退出后，下次启动先持有根锁并处理恢复记录，再创建仓库和后台任务。没有自动重启。
- Data 页提供手动检查更新、当前 Desktop 版本与构建提交。只能打开受信任的 Desktop 发行页面，不自动下载安装。没有已发布版本时不能把它冒充升级成功。
- 截图只选择文字和图片。预览在单独子窗口中，可保留选择窗口，使用双向滚动、适应宽度、适应窗口和 100%。预览缩放不会改变导出 PNG；录音不会进入选择或渲染。

## 恢复失败时的数据保全

- 文件选择取消、离线校验失败、密码错误或超限：当前数据不应被替换；保留源归档。修正输入后可重新检查。
- 整应用恢复预约完成：必须走正常退出。关闭流程仍需等任务排水和根锁释放，不能通过结束进程跳过安全关闭。
- 下次启动在写入途中中断：启动恢复使用 retained old/new 文件校验并回滚；如果发现不属于旧值或新值的未知内容，停止准入并保留现场，不以默认数据覆盖。
- `backups/.restore-app.tmp` 下的恢复记录由程序持有；已完成记录仍保留。不要通过删除或重命名记录绕过启动拒绝，也不要把它作为可任意清理的缓存。
- 单会话恢复/索引也有独立的恢复记录。发生无法确认的恢复错误时，保留错误提示、版本/commit、归档原件和原数据目录，停止进一步写入；诊断先使用不含密钥和聊天正文的元数据。真实目录的人工修复需单独确立恢复路径。
