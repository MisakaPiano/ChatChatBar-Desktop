# Unwired contracts and trust boundary

FreshRootPreparation accepts only injected/synthetic root generation, protected-context/typed-target metadata and G2A mapping/participant evidence. B+inactive fresh-root, distinct roots, monotonic generation, fresh/inactive destination, matching protector, expected target identity, retained legacy keys and complete declared consumers are required even for synthetic consistency. Unknown/offline/clone/Community/conflict/missing-participant evidence blocks. All outputs keep restoreAuthorized=false, authorizesBusiness=false and durableAuthorityEstablished=false. A SYNTHETIC_VERIFIED enum or matching ID/path never attests SID/DPAPI/account identity or global consumer closure.

Recovery transitions delegate to the G2A pure phase/OLD/NEW witness validator after fresh-root checks. INTENT_DURABLE is an asserted model phase, not a persisted fact. No profile anchor location, serialized intent, namespace, lock/CAS, real key value, native protector or production authority is created.

DormantPreservationPreparation is memory-only: exact raw record copies, typed kind, source references and independent media byte copies. Known strict schemas only; IDs/Task.postId/card/session/sender/voice owner and unknown explicit version are checked. Three distinct image fields are validated individually. Unknown supplied media refuses rather than silently disappearing. No filesystem/network/Task/playback interface exists in the production component. Returned buffers are defensive copies. The test-only adapter materializes candidate bytes into NEW synthetic directories; those filenames are test witnesses, not a deployable schema.

Capacity is a bounded prototype formula: two complete raw+media sets plus caller-supplied synthetic reserve, checked overflow and size limits BEFORE candidate allocation. It is not the final production disk reservation/rollback quota. Exact raw/media identity, interruption and copy experiments do not prove snapshot/full backup/GC/Portable/downgrade/P13 participation. All participation and publication remain false/unimplemented.
