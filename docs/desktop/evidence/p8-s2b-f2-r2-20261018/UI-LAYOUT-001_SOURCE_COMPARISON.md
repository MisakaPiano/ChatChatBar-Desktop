## 数量与布局结论

统计可实例化操作控件，包含两个库切换项，排除输入框、排序下拉、窗口标题栏X；失效按钮仍计数，不表示同屏可见。

- 原版：库切换2＋搜索1＋分页2＋关闭1＝固定6；每卡预览/使用2。共 `6+2N`。
- Desktop：上述同类固定控件＋独立停止1＝固定7；每卡官方样本/生成重播/选择3。共 `7+3N`。
- 本夹具N=2，原版10、Desktop13。确实多出3个控件，不是所有按钮都由Desktop额外发明。
- 原版一个预览按钮根据文本是否为空选择下载/生成；Desktop显式拆分有助于避免把TTS授权与公开样本下载混淆，但不要求两个操作都成为常驻长按钮。
- 原版语言/标签同排、每卡两个按钮同排、预览输入和筛选与结果一起滚动。当前Desktop语言/标签分行、每卡三长按钮纵排、固定顶部占去较大高度；截图直接显示第二音色及其操作被挤到视口下方。这比单纯控件数更显著。
