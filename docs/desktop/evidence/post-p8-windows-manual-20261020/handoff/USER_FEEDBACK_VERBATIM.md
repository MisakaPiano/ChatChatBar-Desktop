## 用户回来后的完整窄窗/播放意见

> 我回来了，我发现几个问题，窄版时候的右键窗口不能超出窗口范围悬浮，整条生成没有重新生成，角色音色默认收起的是角色名字长度，而且不是悬浮按钮，收起的时候可以简化为旁边：角色名……，只有在不够宽的时候收起，极限是只保留旁白两个字，左边的生成状态则可以无限省略。重点是三个需要在同一行。录音操作应该收起到语音右边的…或者对语音条右键的时候展开，现在变窄之后文字就乱了，应该变成类似编辑对话内容的按钮浮窗而不是展开栏。语音本身只保留播放键和时长以及动态的正在播放图标就可以了，固定比和对话条窄一个…的位置，并且现在播放中再点击语音条的播放会重播，再点击就卡住了。我认为播放当中可以停止或者暂停，并且最好能拖动进度比较好，而且不要额外增加纵向长度比较好。
