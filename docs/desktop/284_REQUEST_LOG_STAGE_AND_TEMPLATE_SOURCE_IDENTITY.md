# 284 — 请求日志的实际阶段与模板源码版本

D01后继源码，不改变任何Prompt原文或请求消息，不增加模型调用。公开1235/sign17不变。

原全局日志已有版本筛选，但生产入口没有填写版本。现构建任务把实际共享Prompt目录源码及Android PromptTemplates facade作为声明输入，按文件名排序、统一LF并加边界后生成SHA-256，写入原`desktop-build.properties`。不使用当前Git提交、应用版本或用户正文猜模板版本。

各请求生产入口明确传入本次用途和阶段：聊天、角色补全/改写/外貌/研究、格式卡、世界书、图像识别、NAI设计/研究/修复、朋友圈、Fish翻译/标签和记忆/RAG。日志版本由真实编译输入指纹与用途/阶段共同生成。它表示整个模板源码集合的保守版本，不等于单一自然语言模板的逐字版本，也不声称与Android旧指纹算法的输入集合完全一致。

同一逻辑记忆请求从总结转入修复时保留原记录与物理尝试计数，并记录各阶段身份；筛选可以找到前面阶段的版本。没有声明用途/阶段的入口仍显示未记录；旧构建缺少指纹时仍显示未记录，不补造值。媒体图像/Fish原始网络数据继续使用原独立统计，不把媒体请求伪装成文本模板。

新增合成检查包括源码/阶段变化的身份区分、缺失元数据、打包属性可读、阶段沿袭与版本筛选及清除，以及实际NAI设计/图像识别与Fish网关的日志归属。均待本源码精确云验；不能以源码存在宣称测试或真人通过。
