# Codex commit review

Given a branch, commit or PR, inspect the real GitHub diff rather than only the Codex summary.

Check:
1. task goals;
2. scope creep;
3. CCB Package/Entity/Prompt/WorldBook/provider/memory semantics;
4. platform code isolation;
5. Android regressions;
6. tests and missing tests;
7. required updates to FEATURE_PARITY / UPSTREAM_COMPAT / CURRENT_STATE.

Result:
- PASS
- PASS WITH FOLLOW-UP
- CHANGES REQUIRED
