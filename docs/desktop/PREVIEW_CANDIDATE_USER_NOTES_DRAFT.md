## 本轮提供的能力

- Windows 原生聊天、语音、图片、资料检索与记忆，数据持续落盘。
- 手机全应用备份先检查和预览合并，保留电脑与手机独有内容，重复、同名、分叉聊天和账户冲突由用户选择。仅加载手机资料不等于完成合并。
- 已选凭据进入独立 Windows 保护存储；普通整应用分享备份排除已配置凭据，账号归属仍需用户核对。
- 保全历史录音、消息版本、朋友圈记录及相关媒体；不宣称完整 Moments、Community 或后台任务已经实现。
- 整应用备份导出、受支持对话存档导入导出、资料目录选择，以及手动检查 Desktop 更新和打开可信发行页。
- 普通首装、同包重装、升级、稳定快捷入口及卸载。新版正常显示并确认启动后才切换入口，卸载保留资料和凭据；升级前正常关闭程序。

## 安装与使用

1. 在 Windows x64、本地 NTFS 磁盘上运行普通安装包。本机授权长期程序位置为 `H:\ChatChatBar-Desktop-App`；程序与资料目录分开。
2. 打开“数据”页核对当前资料目录和已有内容。正式机制保留已有资料选择；不要把备份、聊天资料或凭据放入程序目录。
3. 手机迁移前保留原始导出，核对冲突和凭据来源，再选择新位置确认合并。成功后正常退出重开，检查双方独有会话、消息版本、图片和录音；不要立即删除旧资料、旧凭据和快照。
4. 升级前导出备份并正常退出，再运行新版安装包。程序回退不等于资料回退；仅备份程序文件也不等于备份全部资料和凭据。
5. 失败时保留原包、原资料和失败现场，不清空目录、不删锁文件、不手改版本指针。不能确认安全关闭时使用“重试安全关闭”。
6. “版本与更新”可复制基本诊断。公开反馈只附版本、操作步骤和脱敏提示，不上传原始备份、密钥、密码或完整私有日志。

安装器只管理其所属程序文件。未知或改动文件保留并显式记录；管理日志位于用户 LocalAppData 的独立安装状态目录。新程序根只授予当前用户、SYSTEM 和管理员管理权限，不改资料和父盘权限。长期程序根不放探针、故障包、假资料或测试日志。
