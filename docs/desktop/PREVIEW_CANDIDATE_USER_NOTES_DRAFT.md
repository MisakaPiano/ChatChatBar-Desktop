# Desktop Preview 1207 发行说明

当前已公开发布 `0.1.0-preview.1207`，Windows 安装版本 `0.1.1207`，构建源码 `bd385a995fbb506e16607dc92403755951a591a4`。普通安装包使用当前用户 NSIS EXE；此前 MSI 路线无限期搁置。实际包摘要、原生验证和安装状态以 [207 当前总账](207_CONTINUOUS_START_AND_DELIVERY_LEDGER.md) 为准。用户已完成本机版本、原有内容及草稿正常退出重开限定验收。[公开发行页](https://github.com/MisakaPiano/ChatChatBar-Desktop/releases/tag/desktop-v0.1.0-preview.1207)提供安装包和校验文件。

## 本轮提供的能力

- Windows 原生聊天、语音、图片、资料检索与记忆，数据持续落盘。
- 手机全应用备份先检查和预览合并，保留电脑与手机独有内容，重复、同名、分叉聊天和账户冲突由用户选择。仅加载手机资料不等于完成合并。
- 已选凭据进入独立 Windows 保护存储；普通整应用分享备份排除已配置凭据，账号归属仍需用户核对。
- 保全历史录音、消息版本、朋友圈记录及相关媒体；不宣称完整 Moments、Community 或后台任务已经实现。
- 整应用备份导出、受支持对话存档导入导出、资料目录选择，以及手动检查 Desktop 更新和打开可信发行页。
- 普通首装、同包重装、升级、稳定快捷入口及卸载。新版正常显示并确认启动后才切换入口，卸载保留资料和凭据；升级前正常关闭程序。

## 安装与使用

1. 在 Windows x64、本地 NTFS 磁盘上运行普通安装包。本机授权长期程序位置为 `H:\ChatChatBar-Desktop-App`；程序与资料目录分开。
2. 打开“数据”页核对当前资料目录和已有内容。正式机制保留已有资料选择；不要把备份、聊天资料或凭据放入程序目录。
3. 手机迁移前保留原始导出，核对冲突和凭据来源，再选择新位置确认合并。成功后正常退出重开，检查双方独有会话、消息版本、图片和录音；不要立即删除旧资料、旧凭据和快照。
4. 升级前导出备份并正常退出，再运行新版安装包。程序回退不等于资料回退；仅备份程序文件也不等于备份全部资料和凭据。
5. 失败时保留原包、原资料和失败现场，不清空目录、不删锁文件、不手改版本指针。不能确认安全关闭时使用“重试安全关闭”。
6. “版本与更新”可复制基本诊断。公开反馈只附版本、操作步骤和脱敏提示，不上传原始备份、密钥、密码或完整私有日志。

安装器只管理其所属程序文件。未知或改动文件保留并显式记录；管理日志位于用户 LocalAppData 的独立安装状态目录。新程序根只授予当前用户、SYSTEM 和管理员管理权限，不改资料和父盘权限。长期程序根不放探针、故障包、假资料或测试日志。

## 验证范围与限制

- Windows 10 Pro 19045 x64 上，1202/1203/1206 的普通首装、同包重装、升级、占用拒绝、降级拒绝和卸载已有实测。真实 GUI 正常开关后，隔离资料、图片、bootstrap 和三项人工合成 DPAPI 值独立回读通过。1207 最终结果另列总账，不用此前版本代签新包。
- 安装程序尚未具有发布者数字签名，Windows 可能显示未知发布者提示。包摘要用于核对下载字节。
- 正式上游基线仍为 ChatBar 1.4.1 `5e76a9cb841736bbbf3499a2e35e5789af4c5ca8`。选定 1.4.5–1.4.7 备份格式的有界适配不代表完整支持这些版本或最新上游。
- 现代 code86/v2 全备已在隔离 Desktop 完成认证、合并、重开、离线续聊及再导出。官方解码器检查、旧 code84/v1 的 Android 仪器验证、对话存档 Android 往返各有独立范围；现代全备在 Android 的完整整应用恢复和物理设备往返尚未完成。Desktop 专有保全域不宣称 Android 可恢复。
- 便携对话存档上限 256 MiB；全应用流式路径限制源文件和展开总量各 4 GiB、单文件 256 MiB、结构化内容合计 64 MiB，另有单 JSON 和文件数量限制。受控目录迁移复用这些限制，压缩体积符合不保证展开后符合。
- 损坏、未知结构、缺少资源、超限或预览后源状态变化会拒绝提交，不是所有历史及未来格式都已支持。
- 跨 Windows 账户、断电时完整应用恢复、真实大包历史快照恢复、全部媒体和凭据语义尚未全面验证。小型快照演练、文件可解析或包哈希一致均不能代替这些验证。
- 目前支持手动更新发现和普通安装包升级；完整自动下载、安装、重启及广泛系统集成仍是后续工作。Preview 不代表 1.0 功能对齐。

## 最短人工验收

正式安装后，从桌面快捷方式打开，确认“版本与更新”为 `0.1.0-preview.1207`；在“数据”页核对原资料位置和已有内容。保存一段无需联网的草稿，正常退出后再打开，确认草稿仍在。按实际情况反馈通过或具体异常，无需付费模型请求。故障测试弹窗的“确定”和沉默均不算验收。
