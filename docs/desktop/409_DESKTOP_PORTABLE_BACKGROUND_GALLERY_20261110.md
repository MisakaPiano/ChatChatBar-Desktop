# 完整角色卡11与跨端背景图库

当前用户已明确要求Android与Desktop同时携带全部背景、独立封面及默认背景。共享Entity新增`chatBackgroundImages`，Package新增`chatBackgroundImageResourceIds`，与独立封面及默认背景分别保存。完整11成为普通JSON/PNG导出的默认；显式兼容9会警告省略封面、图库与人物启用状态。读取3–11按实际字段校验，兼容旧Android图库10和Desktop封面10；不以相同格式号冒充双端验证。

背景按引用首次出现顺序去重，不按字节合并。默认背景可在图库外；缺少实际引用图片时完整导出失败，不能静默漏图。人物启用状态规范输出`enabled`，兼容读取旧`desktopEnabled`。会话覆盖、Desktop首选与卡片默认互相独立；切换背景不调用模型，不触碰既有Prompt文本。

旧Desktop库只读导出投影会携带其现有图片。用户主动迁移时先保存卡片图库，再标记旧库已迁移；中断最多重复引用，保留旧库与文件。新添加图片保留编码字节。旧库历史上已归一化的PNG只能保留其现有字节，不能恢复外部原始编码。迁移后移除图库项不会由旧库重新带回。草稿materialize、编辑保存、资源清理、备份映射与恢复一并处理图库引用。

固定Android源`2fd7c2b08641b9f255312822919e7c2ce15bd871`的实际合成JSON/PNG导出已作为带原始散列的测试资源纳入；定向验证将运行生产Desktop导入/导出与重开、重复往返、旧库迁移、默认选择、缺失文件、全选/部分备份和草稿恢复。输出再交Android执行第二腿。当前只是实现与待验收范围，不表示双端已全通过、用户验收或新版本公开；1250和签名32不变。
