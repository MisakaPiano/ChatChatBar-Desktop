# 文档PDF与截图PDF

1243的PDF出口只将PNG截图分页嵌入；此前实际“PDF/Word状态栏和选项均关闭”通过仅代表所测内容过滤，不代表已有文档型PDF。

新增默认“文档 PDF”，与Word复用`desktopScreenshotDocument`不可变选择投影、Markdown runs、三类语义样式、头像、配图与页面背景。`DesktopDocumentPdf`用PDFBox写入真实文本和嵌入媒体，按文本宽度独立换行分页；中文及常用emoji使用程序内字体，导出不联网、不依赖安装Word/WPS。原图片分页功能仍以“截图 PDF”保留，PNG与可编辑Word操作保留。

两种结构化文档共用资源收集／SHA复核、原生选择位置前后消息核对、取消及原子落盘。文字240000字符、资源40项／32MiB及原解码像素约束保持，文档分页另有上限。正文不是隐藏的整页图片，也不通过静默栅格回退掩盖字体或资源错误。字体原件、来源、SHA及许可证在`src/main/resources/document-fonts/`，所用字形按文档嵌入；具体字体覆盖外的Unicode明确拒绝，不丢字。

受影响检查包括实际中文／英文／emoji提取、三类样式、四种独立过滤组合、真实分页和重复背景／头像配图，以及取消、消息／资源变化拒绝和原文件保全。原Word与截图PDF回归独立保留。定向云端原件与合成PDF／首末页PNG用于审查；真实用户文件、提供者请求与后继公开许可不由这些检查推断。
