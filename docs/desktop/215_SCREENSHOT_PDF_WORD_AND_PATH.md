# 215 聊天截图 PDF／Word 与保存路径

2026-11-01 JST。用户要求社区排在最后、先完成前面的事项；继续 SF07／SF08，不启动新大 phase。用户明确选择 Word“文字可编辑，图片嵌入文档，排版可与聊天界面略有不同”；PDF 保留截图外观。

## 实现范围

- 保留截图选项树、分段 ID、消息顺序、状态展开选择与 PNG 预览／导出。格式选择提供 PNG、PDF、Word（`.docx`）。
- PDF 复用预览的完整无损图片，在 A4 页面连续裁切分页，不改变原图比例；不声称 PDF 文字可编辑或可搜索。
- Word 从同一份选中内容快照生成可编辑文字和内嵌图片。段落使用已有角色显示名；不导出未勾选正文、推理、录音或折叠状态正文。Word 不复刻背景／气泡外观，不依赖远程图片。
- 选择保存位置后再次核对消息版本与资源；Word 的图片实际读取再次核对捕获 SHA。三种格式共用新文件写入和临时文件清理；不覆盖已有文件。
- 仅保存成功后显示实际路径与“复制路径”；取消、失败、新预览或改变选中内容不显示旧成功路径。剪贴板繁忙按现有受控重试处理；复制失败不谎称导出失败。
- 使用 PDFBox 3.0.8；OOXML 使用 JDK XML／ZIP 写入器，不引入文档脚本、宏或外部资源链接。
