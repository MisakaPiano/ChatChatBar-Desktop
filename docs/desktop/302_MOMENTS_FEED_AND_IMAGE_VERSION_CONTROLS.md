## 行为与呈现

- `DesktopMomentFeedCard` 在有限宽度的信息流中保留独立头像侧栏，昵称、正文、配图左边界一致；昵称行右侧放编辑，配图下方是紧凑时间/私密标记和重生成、删除、点赞操作。复制与图片版本管理留在更多菜单。
- 图片下方的 `DesktopVersionControls` 与聊天回复共享箭头/计数/方向禁用样式，动态使用图片语义标签。当前n依据原post.imagePath匹配retained版本，方向选择原版本ID，调用原controller→store原子保存；只有一版显示1/1并禁用方向。
- 不改Moment实体、图片保全/清理/备份或历史版本身份，不覆盖重生成前的图片；版本预览、显式选用和确认移除窗口保留。重生成图标只打开原编辑/确认流程，仍由用户确认付费请求。
- 头像/昵称点击仍解析原动态的精确会话；右键仍有所属角色卡及朋友圈开关入口。不按同名猜测或新建会话。相册、时间线和返回原动态继续使用原导航/滚动位置。
