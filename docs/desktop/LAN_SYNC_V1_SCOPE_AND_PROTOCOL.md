每份快照必须显式声明完整 `coveredTypes`；双方与共同基线覆盖不匹配时拒绝比较，不把未参与的数据解释成删除。`excludedTypes` 为本次本机观察到的未参与类别。共同基线绑定证书设备身份、协议/覆盖及双方完成回执。单侧已应用时保留事务，不宣称两设备原子提交。

二维码只含局域网地址、端口、证书摘要、有期限的一次性随机能力；不含账户、密钥或用户资料。手机明确确认后以固定证书身份连接；UDP发现结果没有信任权限，必须再通过固定证书的双向TLS。设备身份在Windows由DPAPI保护，在Android由Keystore保护。撤销配对立即取消后续认证权限，保留既有数据/基线/失败证据。

媒体在进入快照前转为内容hash引用，路径与时钟不参与合并选择；正文与扩展保持原文。共享快照和本机提交有明确单记录、总量限制，超限拒绝并保留原数据，不能悄悄部分同步。启动恢复必须先于repository/cache初始化；写入前完整核验日志、旧/新payload和全部目标，实际中途崩溃由已授权日志继续恢复。

必要工程验证只在云端运行，使用人工合成记录与媒体；没有手机真机、真实Wi-Fi或真人验收证据时明确保持未测。实现中持续对照主线，仅在隔离副本验证合并，不直接改主工作区或公开发布。
