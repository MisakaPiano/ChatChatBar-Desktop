# 管理与设置的保留模型选项

2026-11-08。继续 1.4.11 非 Prompt 消费者适配；本批源码及 2 项合成检查尚未编译、执行或交付。

原管理/设置控制器只在 loadModels/loadSettings、自己的提交/恢复操作时刷新列表。其他入口修改模型或默认选择后，保留中的语音、格式修复及生图设置选择器可能仍显示旧名称或旧可选项。

DesktopManagePanel 在自身组合生命周期内启动一个 observeModelChoices 订阅，明确重试修订变化时取消旧订阅再重读。控制器消费原 EffectiveModelResolver 配置流，只发布脱敏模型摘要、对话/辅助选项、默认身份和诊断；不重新 loadSettings，不替换 settings/editor 草稿、dirty、leave、凭据编辑或正在运行任务。删除后的显式草稿 ID 保留，由原 UI 显示缺失，不能静默替换成默认模型。

desktopEffectiveModels 的冷调用现在先取得一份配置，再从同一份配置派生对话/图像默认身份。管理页观察者也直接使用收到的配置；默认诊断仍由原 desktopModelDiagnostic 计算，实际密钥只用于领域层/临时读取，不进入状态摘要。

读取失败保留旧摘要并显示独立失败状态与明确重试读取入口，不能当成功空目录或抢占普通编辑错误。取消继续传播；重试不改写密钥或发送模型请求。新增 DesktopRetainedModelChoicesTest 使用内联目录及合成保护存储，覆盖同 ID 改名/增删/默认变化、未保存设置与编辑器保持、显式失效选择保持，以及冷保护读取失败后的显式恢复和无密钥 UI 摘要。
