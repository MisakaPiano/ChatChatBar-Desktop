# 主窗关闭到托盘、任务摘要与显式更新缓存维护

本批保持已公开1250及签名32不变。`closeWindowToTray`默认关闭，经Desktop设置原子保存后生效；外观设置和任务中心共享同一托盘所有者。仅正常Idle主窗关闭允许隐藏，真正退出经过聊天/记忆、世界书、格式卡、角色和模型既有未保存处理，再到原根迁移守卫与关闭排空。根迁移、强制重启和更新退出保持原路由；托盘不可用或摘要失败保持可恢复的可见窗口。

托盘悬停和五行右键摘要只投影任务中心已有状态，不包含上下文正文或凭据；运行、等待/排队、停止中与待核对分别表示，零任务不意味着无未保存内容。程序更新/缓存维护投影其原Job与UUID，Stop不会转投下一Job。辅助进程启动前检查取消，返回时等待该进程退出；不确定的交接/退出保留待核对状态。

更新空间门限仍为目标长度三倍加64MiB，详情包含实际缓存盘、路径与所需/可用字节。新增显式“清理旧更新安装包”入口，不新增开机清库。原client.lock内只处理已核UUID目录中的确切EXE，Windows独占句柄核最终路径、单链接、长度与哈希后删除。保护当前版本、已选目标、各缓存通道目标及两份近期包；未知、占用、不一致和未确认材料保留，全部VERIFIED/TUF小证据不删不重置，不清理Program版本或用户资料。重复清理只报告保留的小记录，不重复计数。

绑定原主动作与afterChange导航分离：服务返回成功即固定主结果，后续导航/列表刷新取消或失败不再冒充主提交失败。原未返回成功且发布已尝试的状态继续待核对。首轮00f源10类64项与a085源10类93项分别有云端原XML，原Windows更新器19项含真实独占句柄和链接检查；各组按实际范围复用。run42673235376的独立AWT Frame/原托盘后端支持true，隐藏、菜单恢复、dirty守卫退出、work排空和icon/Frame释放实际通过。普通1251原EXE/随包runtime升级与重开检查单独通过；run42683130339复用原包，外部CI JDK17按原cfg启动实际包内Main，隐藏/菜单恢复/真退出、原MAIN_RETURNED→SAFE_EXIT_HANDOFF记录、观察性JVM退出hook的window/icon释放及全Job exit0/空树全部实际通过，未替换原exitProcess、不要求反射调用返回。此范围与dirty Frame/守卫、OS鼠标及人验分开；先前编码、图形库路径、无效合成设置/反射返回假设三次工具失败均保留，不改旧记录。
