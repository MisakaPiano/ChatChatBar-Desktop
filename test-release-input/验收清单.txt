CCB 集中验收 r1：新增部分清单

这是独立测试应用，可以与正式版、c1、n1并存。界面里没有离线模拟开关；异常、限流和批次内部验证由云端测试完成。
本轮先看界面、配置和保存，不点“生成”“重新生成”“AI修复”等会发请求的按钮。不用提供Token、API Key或私人聊天。

准备
1. 安装集中验收APK，首次启动进入首页。
2. 解压“合成资料.zip”。旧的“完全合成-备选与修复验收.cbbackup”仍可沿用，或用本次资料里的同一份合成备份。
3. 在测试应用的数据迁移/备份导入入口恢复合成备份，按提示关闭并重开。应恢复成功，不应因这次正常关闭新增“异常退出”提示。旧的未处理崩溃报告可能仍存在，请区分时间；不要为测试覆盖日常版数据。
4. 回到角色页，单独导入“集中验收完全合成卡.chatbar-character”。不要导入整个ZIP。

A 封面与背景库
[ ] 角色卡编辑里有独立的封面原图与3张背景。只改名称或文字保存，封面和背景保持。
[ ] 导出图片卡时，可从卡内图片“选为底图”，并“单独保存底图文件”；改导出文字后再选同一底图，原图文件不应被改写。取消导出不改变卡片。
[ ] 从这张卡创建会话，无需发消息。会话设置→聊天背景可见同一背景库。
[ ] 在会话设置中添加一张测试图片，卡片编辑里也能看到。会话覆盖与Android卡片默认可分别选择；更改默认不改当前会话覆盖。
[ ] 从图库移除一个条目，已选默认或已使用的会话背景仍保留。可重新添加；移除不是删除原图。
[ ] “裁剪副本”取消不变；确认后多一张副本，原图仍在。两处图库都有保存原图与裁剪入口。
[ ] 导出完整角色卡，再导入副本，封面、全部图库和Android默认保留。旧兼容格式会省去新增字段，本项用完整格式。

B 玩家与人物状态
[ ] 会话设置可设置玩家头像、关联测试人物，并分别控制跟随姓名/头像；解除后恢复会话覆盖或全局默认。
[ ] 文案明确：头像用于显示，姓名用于提示词和变量，关联不会复制人物简介；本项不发模型请求。
[ ] 聊天顶部人物入口可展开列表。甲、乙的剧情状态可展开/收起；丙在卡内关闭。只查看状态不会修改人物开关。

C 字段估算和会话图片
[ ] 角色卡及世界书编辑器能打开“字段 Token 估算”。默认排除停用内容、备注、生图词；世界书标为候选，不能当作本轮已激活量。
[ ] 会话设置→会话图片能查看当前会话已保存图片；选择图片后可定位回原消息。空会话显示暂无图片。
[ ] 图库与查看器保留重复附件的各自来源；关闭查看器后再次点同一张图，应从点选的图片打开。刷新不自动切换已打开的图片。

D 批量生图设置（只配置，不开始）
[ ] 会话生图设置为“每批张数 × 生成批数”；4张×3批显示12张，无目标张数或手填积分预算。
[ ] 数量超出范围会截到有效值；等待方式横排，固定/随机可输入1.5、2.3等小数。
[ ] “允许消耗 Anlas”默认关闭。估算费用由应用显示；没有Token时可保留未配置状态，本轮不用为了测试填写。
[ ] 各会话设置独立，保存后重开保持；保存本身不启动生成或打开自动生图。
[ ] 图片操作默认关闭“使用已保存批量设置”，显示普通单张和费用预估；打开后才用保存的批量方案。不点重新生成。
[ ] 工作室使用相同数量、等待和付费开关；暂停/继续/停止只在任务运行时出现，内部运行行为已由自动测试覆盖，本轮不用触发真实任务。

E 已通过功能快速观察
PR7原来的备选保留、删除到0、本地撤销/重做与朋友圈切图已验收，本轮不要求整套重测。合成备份里的26个备选和修复消息是两条独立回复；删除其中一条不会删除另一条。
若查看朋友圈，红/绿两张备选及对应资料仍能切换并在重开后保留。不要点击真实重新生成。

反馈按A1、A2……填“通过/有问题/未测”，描述操作与实际表现即可。不要发送真实凭据；图片/角色卡反馈请先压成ZIP以免被平台当图片压缩。

仍未包含：行动选项按钮点填、聊天纯编号处理、多个场景入口、启用组合与触发启停、按剧情读服装参考文档。显式行动区只在生图研究/设计输入中排除，原文和聊天显示保留。
